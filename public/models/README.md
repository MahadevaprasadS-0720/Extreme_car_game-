# BMW M4 3D Model Directory

Place your `bmw_m4.glb` file here:

- Expected path: `/models/bmw_m4.glb` (served from `public/models/bmw_m4.glb`).
- When present, the vehicle loader hook (`useVehicleModel`) will automatically detect and load it, applying custom PBR clearcoat car paint, transmission glass, and emissive lighting shaders.
- If absent, the environment automatically renders the built-in, highly detailed procedural BMW M4 Competition Coupe (G82).
